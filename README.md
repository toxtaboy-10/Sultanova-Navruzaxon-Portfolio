# Sultanova Navruzaxon — Academic Portfolio

Static website built with HTML5, CSS3 and vanilla JavaScript.

## Run locally
Open `index.html` directly or use VS Code Live Server. No build step is required.

## Deploy
Upload the contents of this folder to GitHub Pages or any static hosting provider.

## Editable information still required
- A dedicated portrait photograph (the supplied archive contains event/activity photos, not a clearly identified portrait).
- Exact scientific article title, journal name, issue and publication date.
- Article certificate, related diploma and review images/PDFs.
- Personal certificates, diplomas and honorary awards.
- Email, Telegram and Instagram addresses.
- A verified context/title for the supplied video, if a more specific caption is desired.

The website intentionally uses placeholders instead of inventing missing facts. The contact form is not connected to an email backend.
